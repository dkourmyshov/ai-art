## Piece 5: QUASICRYSTAL — Wave-Interference Aperiodic Lattice (2026-07-02)
Closed-form superposition of N plane waves evenly spaced by angle π/N. When N
is not a multiple of 4 the field is aperiodic — a mathematical quasicrystal:
long-range orientational order without translational periodicity, the
structure Dan Shechtman discovered in an Al-Mn alloy in 1982 (forbidden
fivefold diffraction symmetry, 2011 Nobel Prize in Chemistry). Same family of
pattern produced today by laser interference lithography for photonic
bandgap materials.

### Why this piece is architecturally different
Every prior piece (MEMBRANE, LENIA, EXCITABLE, PHYSARUM) is an iterative
PDE/agent simulation requiring a ping-pong framebuffer and per-frame state
history. QUASICRYSTAL has none of that: the field is a pure closed-form
expression (sum of cosines) evaluated fresh per pixel per frame from
`uTime` alone. No simulation texture, no framebuffers, single draw call.
Deliberately chosen as a break from the "biological continuous field" run
of the first four pieces — crystalline/mathematical register instead of
organic — after web research turned up quasicrystal interference lithography
as a good tonal fit for a "novel and unexpected" net.art piece.

### Technical Stack
- Pure WebGL1, no extensions required at all (no OES_texture_float — the
  first piece in the gallery that needs none, since there's no float
  texture state to carry between frames)
- field(p) = (1/N)·Σ cos(p·dir_i·freq + phase_i), dir_i at angle i·π/N + slow
  rotation drift; phase_i uses a golden-angle-ish increment (i*2.399963) so
  the N waves desync from each other over time instead of pulsing in unison
- Chromatic dispersion: R/G/B channels sample the field at freq·(1±disp),
  producing prismatic fringing at bright ridges — literal optical accuracy
  (different "wavelengths" refract at different frequencies), confined to
  peak regions via a smoothstep mask so it doesn't wash out the troughs
- Facet edge lines: thin bright contours at fract(field·lines) ridges,
  masked to peaks only — reads as crystal facets catching light, not a
  topographic contour map (see palette tuning trap below)
- Palette: 3-stop smoothstep gradient (near-black trough → jewel mid-tone →
  bright peak), NOT an IQ hue-rotating cosine palette — see trap below

### Palette tuning trap (future sessions: read this before using IQ cosine
palettes for anything with iso-contour edge lines)
First attempt used the classic IQ cosine palette (a + b·cos(2π(c·t+d))) like
MEMBRANE, driven by the raw field value. Combined with per-ridge contour
lines at multiple fract() levels, this produced a loud rainbow topographic-
map look (blue/green/yellow/orange bands) that didn't match this gallery's
moody, void-dominant aesthetic (compare EXCITABLE's controlled indigo→
purple→cyan→white ramp). Fixed by switching to a 3-stop smoothstep gradient
per mode (near-black → single jewel hue → bright highlight) AND masking the
edge lines / chromatic fringe to only the top ~30% of field intensity via
smoothstep(0.35, 0.9, t), so most of the frame stays black and only ridges
glow. Also had to push the black→jewel transition later (smoothstep(0.15,
0.55,t) → smoothstep(0.38,0.68,t)) — the first version filled too much of
the screen with midtone color instead of staying void-dominant. General
lesson: when a shader value has many iso-contour crossings, a hue-rotating
palette will read as a contour map; use a single-hue-per-mode gradient with
highlights gated to peaks instead, verified via screenshot before shipping.

### 5 Modes (auto-cycle every 32s, named after real quasicrystal symmetries)
- PENTAGONAL:   N=5,  icy sapphire/ice-blue — Shechtman's original 1982 find
- HEPTAGONAL:   N=7,  amber/gold
- OCTAGONAL:    N=8,  emerald/jade
- DECAGONAL:    N=10, rose/magenta — real Al-Ni-Co decagonal quasicrystals
- DODECAGONAL:  N=12, violet with strong prismatic fringing (fringe=0.42,
  vs 0.15-0.20 for the other modes) — the most complex tiling gets the most
  visible chromatic dispersion, tying the effect to the concept

### Interaction
- Mouse/touch: drops a decaying ripple (circular wave, exp decay in both
  age and distance) into the interference field at the click point — reads
  as a lattice defect/excitation propagating outward. Up to 6 concurrent
  ripples in a circular buffer (uRippleP/uRippleT uniform arrays); each
  ripple's contribution is purely a function of elapsed time since it was
  dropped, so no per-frame state/texture needed to age or clear them out.
- Verified visually via headless Playwright screenshots: all 5 modes show
  correct N-fold rotational structure, ripple click carves a visible dark
  cavity with prismatic fringing at nearby ridges.

## Piece 1: MEMBRANE — Gray-Scott Reaction-Diffusion (2026-06-28)
WebGL generative art. Two chemical species react and diffuse across a 2D plane,
producing emergent organic patterns inspired by Turing's 1952 morphogenesis paper.

### Technical Stack
- Pure WebGL1 + OES_texture_float (~200 lines)
- Ping-pong framebuffer, GPU-accelerated PDE solving
- 9-point discrete Laplacian (orthogonal=0.2, diagonal=0.05, center=-1.0)
- 5 simulation steps per frame, sim resolution capped at 640px
- IQ cosine palette: 0.5 + 0.5*cos(2pi*(vec3(0,.33,.67) + t))

### Pattern Modes (auto-cycle every ~30s)
- mitosis:  f=0.0545, k=0.062
- coral:    f=0.0545, k=0.0595
- spirals:  f=0.034,  k=0.063
- maze:     f=0.030,  k=0.057
- spots:    f=0.039,  k=0.058
- stripes:  f=0.046,  k=0.066

### Interaction
- Mouse/touch: seeds V chemical (U=0.5, V=0.9) at cursor

## Piece 2: LENIA — Continuous Cellular Automata (2026-06-29)
WebGL implementation of Bert Chan's Lenia (2018). A single continuous field [0,1]
evolves under dx/dt = G(K*x), where K is an annular Gaussian kernel and G is a
bell-curve growth function. Produces emergent organism-like patterns.

### Technical Stack
- Pure WebGL1 + OES_texture_float (~230 lines)
- Ping-pong framebuffer, same architecture as MEMBRANE
- 11×11 annular Gaussian kernel (ring peak at normalized radius 0.5, ~85 taps)
- 2 simulation steps per frame, sim resolution capped at 512px
- Bioluminescent palette: void→indigo→cyan→jade→white
- Iridescent hue drift via col.gbr swizzle mix (slow oscillation)
- Radial vignette + bloom on high-state cells

### Organism Modes (auto-cycle every ~40s, reseed on switch)
- bloom:   mu=0.200, sigma=0.040, dt=0.100
- weave:   mu=0.150, sigma=0.022, dt=0.090
- fronds:  mu=0.265, sigma=0.044, dt=0.100
- crystal: mu=0.305, sigma=0.056, dt=0.110
- pulse:   mu=0.183, sigma=0.033, dt=0.090

### Interaction
- Mouse/touch: seeds living material (~0.75) at cursor position
- On mode change: full reseed with random circular blobs

### Kernel detail
K(r) ∝ exp(-((r/5 - 0.5)*4)² * 2)  — peaks at r≈2.5px, zero beyond r=5.5
G(n) = 2*exp(-((n-mu)²)/(2*sigma²)) - 1  maps [0,1] → [-1,1]

## Piece 3: EXCITABLE — FitzHugh-Nagumo Excitable Media (2026-06-30)
WebGL implementation of the FitzHugh-Nagumo model (FitzHugh 1961, Nagumo 1962).
Two coupled reaction-diffusion equations model excitable media — neurons, cardiac
tissue, chemical oscillators. Produces rotating spiral waves, traveling pulses,
turbulent breakup, and autonomous oscillations.

### Technical Stack
- Pure WebGL1 + OES_texture_float (~220 lines)
- Ping-pong framebuffer, same architecture as MEMBRANE and LENIA
- 9-point Laplacian on v only (w has zero diffusivity)
- 3-5 simulation steps per frame depending on mode
- Electrophysiology palette: indigo→purple→electric blue→cyan→white
- Warm amber overlay for recovery tails (w high, v descending)

### Equations
- dv/dt = D·∇²v + v - v³/3 - w + I
- dw/dt = ε·(v + a - b·w)

### 5 Modes (auto-cycle every 38s)
- spirals:    a=0.7, b=0.8, ε=0.08, I=0.50 — rotating spiral waves
- pulse:      a=0.5, b=0.5, ε=0.04, I=0.20 — traveling excitation pulses
- oscillator: a=0.8, b=0.6, ε=0.10, I=1.00 — autonomous oscillations
- turbulent:  a=0.7, b=0.8, ε=0.16, I=0.90 — chaotic spiral breakup
- slow wave:  a=0.9, b=0.9, ε=0.02, I=0.00 — broad refractory fronts

### Interaction
- Mouse/touch: stamps circular excitation (v=2.0) at cursor → triggers new spirals

## Piece 4: PHYSARUM — Slime-Mould Agent Simulation (2026-07-01)
WebGL1 agent-based simulation of Physarum polycephalum transport-network
formation (Jones 2010; Tero et al. 2010 "Rules for Biologically Inspired
Adaptive Network Design" — the Tokyo-rail-network slime-mould study). First
agent-based piece in the gallery — everything before it was a continuous PDE
field (Gray-Scott / Lenia / FitzHugh-Nagumo). Distinct visual register:
thin glowing branching networks on black, vs. the previous pieces' filled
organic fields.

### Technical Stack
- Pure WebGL1 + OES_texture_float, no WebGL2 / transform feedback needed
  (earlier sessions had flagged Physarum as "needs WebGL2" — untrue; a
  gl.POINTS + vertex-texture-fetch (VTF) architecture works fine in WebGL1)
- Agent state (x, y, heading, species) lives in a float texture, ping-ponged
  by a fragment shader exactly like the other pieces' simulation textures
- Deposits are rasterized with gl.POINTS whose VERTEX shader reads each
  agent's position via texture2D (VTF) — no CPU readback, no scatter buffer
- Trail field (two channels, one per species) is a second ping-ponged float
  texture: deposit (additive blend) → diffuse (9-tap box blur) → decay
- AGENTS_DIM=384 (147,456 agents), TRAIL_RES=512
- Two competing species: each senses its own trail channel, is repelled by
  the other's (`sensed = own - repulsion*other`) — produces territorial
  boundaries between colonies, not just single-species webs
- Palette: warm amber/yellow (real Physarum polycephalum's colour) vs.
  crimson/magenta, with a hot glow blended in at contact seams

### Sense/turn/move rule (classic Physarum algorithm)
- Each agent samples trail intensity at 3 points: straight ahead (C), and
  ±sensorAngle to either side (L, R), all at sensorDist from current position
- If C is highest: keep heading. If L or R is highest: turn toward it by
  rotAngle. If tied: turn a random direction (hash of texcoord + frame count)
- Move forward by `step` along the new heading; position wraps via fract()

### 5 Modes (auto-cycle every 35s, full reseed of agents + trail on switch)
- NETWORK:   sensorAngle=25° sensorDist=11px rotAngle=28° repulsion=0.08 — clean transport webs
- TERRITORY: sensorAngle=22° sensorDist=9px  rotAngle=32° repulsion=0.65 — competing colony boundaries
- COLONY:    sensorAngle=45° sensorDist=20px rotAngle=16° repulsion=0.05 — slow wide branching
- SWARM:     sensorAngle=12° sensorDist=7px  rotAngle=50° repulsion=0.00 — turbulent flocking streams
- LICHEN:    sensorAngle=32° sensorDist=14px rotAngle=20° repulsion=0.20 — dense space-filling mycelium

### Deposit tuning (mean-field equilibrium)
Trail intensity converges to T_eq ≈ deposit·(agentsPerSpecies/texelCount) / (1-decay).
With decay in 0.90–0.978 and ~73,728 agents/species over 262,144 texels, deposit
must be tiny (0.014–0.06) or the field saturates solid within ~40 frames — this
was the single biggest tuning trap. Target T_eq around 0.15–0.2 so trail-dense
regions (where agents cluster via the positive feedback loop) stand out brightly
above a dim, mostly-black ambient field. Don't reason about deposit amount in
isolation — always check it against decay and agent density together.

### Interaction
- Mouse/touch: boosts both trail channels at cursor (like a food source),
  drawing nearby agents toward it via the normal sensing rule

### WebGL1 gotchas hit during this build (future sessions: check these first
if a ping-pong sim renders solid black or shows no motion)
1. **REPEAT wrap + non-power-of-two texture = silently broken.** WebGL1
   requires CLAMP_TO_EDGE for any NPOT texture; REPEAT on NPOT makes the
   texture "incomplete" and every sample returns black — with NO GL error.
   TRAIL_RES=640 (chosen to match membrane.html's cap) broke this way, and
   AGENTS_DIM=384 broke it a second time for the *agent* texture. Fix: only
   use REPEAT where toroidal wrap is actually needed (the trail field) and
   keep those textures power-of-two; leave everything else CLAMP_TO_EDGE.
2. **gl.ARRAY_BUFFER is global, shared, mutable state — bind it explicitly
   every time.** A `bindQuad()` helper that calls `vertexAttribPointer`
   without first calling `gl.bindBuffer(ARRAY_BUFFER, quad)` silently
   captures whatever buffer some *other* draw call last bound (here, the
   points buffer from the deposit pass), so the "full-screen quad" render
   degenerates into a handful of stray triangles covering almost none of
   the target texture. This produced a bizarre symptom: the sim texture
   alternated frame-to-frame between "genuinely updating" and "frozen at
   its initial random seed," because the corrupted quad draw was a near
   no-op that left the ping-pong texture untouched on the affected frames.
   Every VS/FS pair that shares an attribute name across programs should
   bind its own buffer inside its bind helper — never rely on ambient state.
3. Headless/software-rendered testing (SwiftShader via Playwright) is slow
   per-primitive but NOT the cause of blank renders — don't assume "it's
   just slow," force a synchronous gl.readPixels() to check real buffer
   contents before chasing a performance theory.

## EXCITABLE Technical Notes
### Parameter space (FitzHugh-Nagumo)
- SPIRALS:    a=0.7, b=0.8, ε=0.08, I=0.50, D=0.28, dt=0.05, 4 steps/frame
- PULSE:      a=0.5, b=0.5, ε=0.04, I=0.20, D=0.25, dt=0.05, 4 steps/frame
- OSCILLATOR: a=0.8, b=0.6, ε=0.10, I=1.00, D=0.32, dt=0.05, 4 steps/frame
- TURBULENT:  a=0.7, b=0.8, ε=0.16, I=0.90, D=0.18, dt=0.04, 5 steps/frame
- SLOW WAVE:  a=0.9, b=0.9, ε=0.02, I=0.00, D=0.42, dt=0.06, 3 steps/frame
### Numerical notes
- 9-point Laplacian on v only (w does not diffuse); orthogonal=0.20, diagonal=0.05
- Diffusion stability: dt < dx²/(4D) satisfied for all modes
- Initial conditions: random float field, v∈[-2.4,2.4], w∈[-1.2,1.2]
- Toroidal (REPEAT) boundary conditions
- SIM resolution: 512×512
